# proxmoxlab
Домашняя лаборатория proxmox VE



## 🎯 Цель проекта
Создать рабочий стенд для отработки навыков диагностики, работы с LXC/KVM, настройки бэкапов и автоматизации рутины в среде Proxmox VE.

## 🏗️ Стенд
- **Хост:** VirtualBox (NAT + Host-only Adapter)
- **Гипервизор:** Proxmox VE 9.2.21 (установлен внутри VirtualBox)
- **LXC-контейнер:** `test-ct` (Debian 12, nginx)
- **KVM-виртуалка:** `test-vm` (Debian 13.7, 1 vCPU, 1 GB RAM, 8 GB disk)

## 📊 Сравнение LXC vs KVM

| Критерий | LXC (`test-ct`) | KVM (`test-vm`) |
| :--- | :--- | :--- |
| **ОЗУ в покое** | ~20 МБ | ~175 МБ |
| **Время загрузки** | ~2.512 сек | ~1m20sec |
| **Размер на диске** | ~0.656 ГБ | ~1.2 ГБ |
| **Изоляция** | Общее ядро | Своё ядро |
| **Тип ОС** | Только Linux | Любая (Windows, Linux и др.) |
| **Использование** | Лёгкие сервисы, экономия ресурсов | Полноценные ОС, полная изоляция |
## 💡 Выводы по итогам занятия
- **LXC** — идеален для большинства учебных и рабочих задач (сервисы, веб-серверы, тестовые среды), так как потребляет минимум ресурсов и запускается за секунды.
- **KVM** — необходим, когда требуется полная изоляция или не-Linux ОС. В среде VirtualBox работает медленно из-за отсутствия аппаратного ускорения (программная эмуляция QEMU).
- **Стратегия:** Для дальнейшей учёбы использовать преимущественно LXC, а KVM — для точечных задач, где нужна именно полноценная виртуалка.
